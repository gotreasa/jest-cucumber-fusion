# The jest describe titles and test names this package generated from its committed feature
# files on 2.0.0, captured from a real run of the 2.0.0 tree (npx jest --coverage=false
# --json) before jest-cucumber was removed. A consumer's CI history is keyed on these
# strings, so they are the contract across the major.
#
# READ BY: test/specs/baseline/assert-test-names.js, which runs the repository suite and
# fails unless every suite recorded here is still present and still produces exactly this
# ordered list of names, repeats kept in their positions.
#
# THE POPULATION. The 2.0.0 run held 21 suites. The 9 below are every suite that calls
# Fusion() on a committed .feature file and therefore has names that Fusion GENERATES. The
# other 12 are excluded for a stated reason, so the count is a denominator and not a sample:
#   ambiguous-step-shadowing, hook-error, l2-outline-edge-cases, l4-escaped-parens-outline,
#   m1-before-hooks-clobber, m3-singleton-reset, m4-callsite-resolution and
#   m5-errors-false-silent-skip  -- internal regression tests that stage their own feature
#       and whose own names are deliberately rewritten when they move to the new internal
#       seams;
#   m2-duplicate-matcher, missing-feature-file, undefined-step  -- they drive refusals, so
#       Fusion generates no describe or test from a feature file in them;
#   fuzz-properties  -- its features are generated into a temporary directory from a
#       fast-check seed, so its names are a property of the generator, not of a committed
#       feature file. It asserts its own generated names itself and the whole-repository
#       vector keeps it green.
# A suite added by a later value has no entry here and is not compared.
#
# WHAT A READER SHOULD NOTICE. The order below is the 2.0.0 ORDER, not document order. 2.0.0
# registers every plain scenario of a feature before any Examples row of its outlines, so in
# language.steps.js the scenarios at language.feature:24 and :29 are named BEFORE the three
# Examples rows of the outline at language.feature:12, even though the document puts the
# outline first. Compiling pickles yields document order, so preserving this list is work,
# not a by-product.
